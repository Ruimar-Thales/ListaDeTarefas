<h1>Organizador de Tarefas</h1>

Um site onde você pode adicionar tarefas a uma lista para se organizar melhor. Tudo fica salvo no próprio navegador, então as tarefas continuam lá quando você volta.

[🔗 ACESSE POR AQUI](https://ruimar-thales.github.io/ListaDeTarefas/)

<h2>Funcionalidades</h2>
- Cadastrar novas tarefas<br>
- Listar as tarefas cadastradas<br>
- Marcar tarefas como concluídas<br>
- Editar tarefas<br>
- Excluir tarefas<br>
- Definir uma prioridade para cada tarefa<br>
- Filtrar tarefas por status<br>
- Contadores de tarefas<br>
- Interface responsiva (funciona no celular e no computador)<br>
- Mensagens de feedback para o usuário<br>

.<h2> <strong>Como executar</strong></h2>

<strong>Online:</strong> acesse o link do GitHub Pages acima.

No seu computador:
1. Clone o repositório.

```
git clone https://github.com/Ruimar-Thales/ListaDeTarefas.git
```
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.<br><br>

<h2>Principais decisões de implementação</h2>
- JavaScript puro: o projeto foi feito sem frameworks.
- localStorage: as tarefas são salvas no navegador, sem precisar de back-end ou banco de dados.
- HTML: a página usa tags que descrevem o conteúdo de cada parte.
- CSS: o layout se adapta a telas pequenas e grandes. O visual usa fundo cor de papel, azul bem claro no formulário e na tabela, e a fonte Poppins.
- Passo a passo: o projeto foi construído aos poucos, com commits a cada etapa concluída.
